# Скачать APK

Готовый архив:

```text
downloads/pocket-shift-vr-debug-apks.zip
```

Внутри архива два APK:

- `PocketShiftVR-vrgame-debug.apk` - установить на телефон, который будет в VR-очках.
- `PocketShiftVR-controller-debug.apk` - установить на второй телефон-контроллер.

## Как скачать с GitHub

1. Открой файл `downloads/pocket-shift-vr-debug-apks.zip` в GitHub.
2. Нажми кнопку `Download raw file`.
3. Распакуй zip.
4. Передай APK на телефоны и установи их.

Оба телефона должны быть в одной Wi-Fi сети. В VR-приложении будет показан IP; введи его в приложении-контроллере и нажми `Connect`.
